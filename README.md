# 🎓 交大迎新 Skill

## 上海交通大学全能 AI 校园助手

「交大迎新 Skill」是一个面向上海交通大学学生的校园服务 Skill，覆盖作业追踪、课程评价、校园生活、学术资源和常用校园工具。它把分散在 Canvas、选课社区、水源、交大邮箱以及校内信息服务中的能力整理成自然语言入口，帮助交大学生处理日常学习和生活中的具体问题。

本项目以 [openclaw-sjtu](https://github.com/xhh678876/openclaw-sjtu) 为主要能力来源，在其脚本和数据接口之上增加场景判断、信息组织与迎新导航。本仓库不复制上游实现，安装后仍由 `openclaw-sjtu` 完成实时查询、文件处理和内容生成。

## ✨ 功能一览

### 📋 学业管理

| 功能 | 可以完成的任务 |
|---|---|
| 作业与 DDL 追踪 | 汇总未交作业、截止时间、提交状态和老师反馈，按紧急程度排序 |
| AI 作业辅导 | 读取作业要求和课程材料，提取题目，结合课件讲解知识点与解题思路 |
| 日历同步 | 将课程和 DDL 导出为 ICS，或同步到 macOS 日历 |
| 成绩与课程信息 | 查看 Canvas 课程、成绩及当前身份下可访问的信息 |
| 课件总结 | 提取 PPT、PDF、Word 等材料，整理知识点、章节摘要和复习提纲 |
| 往年资源 | 搜索传承交大的试卷、课程资料和经验内容 |

### ⭐ 选课与校园信息

| 功能 | 可以完成的任务 |
|---|---|
| 选课参谋 | 搜索课程评价、比较同一课程不同教师，整理工作量、考核方式和学生反馈 |
| 水源社区摘要 | 搜索与转专业、保研、实验室、选课等主题相关的帖子，归纳主要观点并保留来源 |
| 教务通知与校内新闻 | 获取教务处通知、交大新闻和相关原文链接 |
| 交大邮箱 | 查看未读邮件、搜索邮件；在确认后发送邮件 |
| 生存手册 | 检索培养、升学、校园生活等经验章节 |

### 🏫 校园生活

| 功能 | 可以完成的任务 |
|---|---|
| 食堂 | 查询食堂信息并按时段给出用餐建议 |
| 图书馆 | 查看场馆位置、开放信息和座位预约说明 |
| 教学楼与空教室 | 查询教学楼和教室信息；静态数据不冒充实时空闲状态 |
| 校园巴士与校历 | 查询校车、教学周、考试周和学期日程 |
| 软件与开发工具 | 查询校内正版软件、镜像源、LaTeX 等在线工具 |
| 视觉素材与 PPT | 搜索视觉交大图片，使用交大模板生成课程汇报或答辩 PPT |

### 🌐 校园社区与生活服务

- 在二手物品、旧教材、失物招领、校园活动、匿名交流和拼车等场景中，提供交大柠檬相应栏目的使用建议。
- 搜索水源社区讨论；恋爱交友场景可介绍水源「鹊桥」，用户明确选择时也可使用上游 SJTU Date 助手。
- 接入龙虾广场 OpenAPI，支持读取 feed、通知等信息；发帖、点赞、私信、举报等写操作必须确认后执行。

## 💬 直接这样问

安装完成后，不需要记住脚本名称，直接描述想做的事：

```text
我这周还有哪些作业没交？按截止时间排一下。
对照老师的课件，帮我讲讲这次作业会用到的知识点。
线性代数不同老师的评价和工作量怎么样？
去水源找一下转专业的讨论，整理主要观点和帖子链接。
把这门课的全部课件整理成期末复习提纲。
用交大模板做一份 10 分钟的课程汇报 PPT。
今天第几教学周？闵行到徐汇的校车怎么坐？
我想收一本旧教材，校内去哪里找比较合适？
```

## 🚀 安装

### 1. 安装交大迎新 Skill

克隆本仓库，然后将 [`skills/welcome-to-sjtu`](skills/welcome-to-sjtu) 复制或链接到 Agent 的技能目录。

OpenClaw 常用位置：

```text
~/.openclaw/workspace/skills/welcome-to-sjtu/
```

Codex 项目级技能位置：

```text
.agents/skills/welcome-to-sjtu/
```

### 2. 安装 openclaw-sjtu

需要实际查询校园数据或生成文件时，按上游项目说明安装：

```bash
git clone https://github.com/xhh678876/openclaw-sjtu.git \
  ~/.openclaw/workspace/skills/openclaw-sjtu

pip install requests beautifulsoup4 python-pptx pdfplumber python-docx Pillow reportlab
```

进入上游目录运行配置向导：

```bash
cd ~/.openclaw/workspace/skills/openclaw-sjtu
python3 scripts/setup.py
```

`humanizer-zh` 为可选的中文润色层，不影响校园功能本身：

```bash
npx skills add ai-zixun/humanizer-zh
```

## 🔑 按需配置

不同功能使用不同服务，不需要一次配置全部凭证。

| 服务 | 主要用途 | 配置 |
|---|---|---|
| Canvas | 课程、作业、DDL、成绩、课件 | Canvas access token |
| jCourse | 课程评价和教师比较 | jCourse API key |
| 水源社区 | 搜索和阅读帖子 | Discourse 链接授权 |
| 传承交大 | 往年资料和试卷 | 登录后获取的 token |
| 交大邮箱 | 未读、搜索和发信 | 邮箱账号及密码或授权码 |
| 龙虾广场 | feed、通知和社区操作 | `lsq_live_*` API key |

凭证只保存在本地配置中，不要提交到 Git，也不要在聊天、截图或日志里公开。

## 🧩 工作方式

```text
用户问题
   ↓
交大迎新 Skill：识别场景、选择校园服务、组织结果
   ↓
openclaw-sjtu：查询平台数据、处理课件、生成文件
   ↓
清晰说明来源、时效、限制和下一步
```

- 实时能力用于 Canvas、课评、水源、通知、邮箱等查询。
- 食堂、图书馆、教学周、校车和教室等部分数据来自上游静态资料，回答时会提示核对当期官方信息。
- 论坛帖子、课程评价和经验内容会与学校政策分开呈现。
- 发信、发帖、提交问卷、点赞、私信、举报、删除等外部写操作都需要用户明确确认。
