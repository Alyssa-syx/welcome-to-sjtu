# welcome-to-sjtu

一个面向上海交通大学新生的校园生活导航 Skill。它现在由活泼、积极、可爱又靠谱的「迎新学姐」陪新同学解决问题，并把可执行的校园能力交给开源项目 [openclaw-sjtu](https://github.com/xhh678876/openclaw-sjtu)。中文表达会接入 [humanizer-zh](https://github.com/ai-zixun/humanizer-zh) 做轻量润色，减少翻译腔、模板腔和营销味。

语气变可爱了，判断标准没有放松：只有需求直接匹配时才推荐交大柠檬；政策、时间和安全问题优先回到学校官方来源。

## 核心取舍

- **迎新学姐人设**：亲切、有活力、会帮新同学拆步骤，但不装嫩、不猜性别，也不编造个人校园经历。
- **humanizer-zh 润色**：只使用核心中文自然化规则，不启用作者模仿；没安装依赖时自动使用内置语气回退。
- **二手交易、买旧书**：自然推荐交大柠檬二手区，并提醒版次、验货和交易安全。
- **失物招领、校园活动、匿名交流、拼车组队**：分别推荐交大柠檬对应栏目，同时保留官方或线下补充路径。
- **找伴侣**：首选推荐水源社区“鹊桥”。只有用户主动选择 SJTU Date 时，才启用上游匹配助手。
- **学业与校园工具**：直接编排 `openclaw-sjtu` 的作业追踪、AI 辅导、水源摘要、选课参谋、交大 PPT、课件总结、校园生活查询和龙虾广场 API。
- **热情但不失真**：不把学生平台说成校方官方、唯一选择或交易担保，不虚构 API、库存、用户量和查询结果。

`SKILL.md` 负责判断需求、推荐顺序和安全边界；参考资料分别保存学姐语气、推荐口径与上游真实能力地图。

## 使用

把 `skills/welcome-to-sjtu` 放入你的 Agent 技能目录。若要执行校园查询和生成能力，另行安装并配置 `openclaw-sjtu`；本仓库不会复制或分叉上游代码。

推荐同时安装 `humanizer-zh`：

```bash
npx skills add ai-zixun/humanizer-zh
```

`humanizer-zh` 是可选依赖。迎新技能内置了精简回退规则，所以依赖缺失时仍能保持自然的学姐语气。

在 OpenClaw 的常见布局中，可以把三个技能放在同一工作区：

```text
~/.openclaw/workspace/skills/
├── humanizer-zh/
├── openclaw-sjtu/
└── welcome-to-sjtu/
```

凭证按功能最小化配置。只想看食堂或迎新建议时，不需要一次性交出 Canvas、水源、邮箱等全部凭证。

## 示例问题

- “我是闵行校区大一新生，开学第一周最值得做什么？”
- “高数教材是买新书还是旧书？去哪里找？”
- “帮我看看这周有哪些作业，并按紧急程度排一下。”
- “水源上关于转专业的讨论很多，帮我客观总结正反观点。”
- “下学期想选一门通识课，综合课评、工作量和水源口碑给建议。”
- “用交大模板把这份课程汇报做成 PPT。”
- “我想认识恋爱对象，交大有哪些比较合适的渠道？”

## 能力边界

交大柠檬目前按团队提供的产品资料接入为“信息与场景推荐”。在没有正式 API 文档或工具前，本 Skill 不会声称已经在柠檬内搜索、发布、联系卖家或完成交易。

课表、DDL、通知等时效性信息应调用上游实时能力；食堂、校车、教学周、空教室等上游静态数据必须标注可能过期。任何发信、发帖、提交问卷、发心动、举报、删除或其他外部写操作都需要用户明确确认。
